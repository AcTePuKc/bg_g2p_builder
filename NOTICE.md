Upstream linguistic and lexical sources referenced by this repository include:

- Kaikki.org exports of Wiktionary-derived Bulgarian lexical and pronunciation
  data. Wiktionary content is community-authored and typically carries
  attribution and share-alike requirements.
- `vislupus/alpaca-bulgarian-dictionary` for Bulgarian stress-marked lexical
  data.
- Manually authored correction, cleanup, and normalization rules maintained in
  this repository.

eSpeak NG is referenced only as an optional engine or comparison point unless a
specific file in this repository explicitly states otherwise. This NOTICE file
does not assert that eSpeak NG code or data has been copied into the repository.

When redistributing generated lexical outputs, downstream users should review
the provenance and license terms of the contributing upstream data sources.
See `DATA_SOURCES.md` and `DATA_LICENSE.md`.
